# Dynamic Island Nav

Expandable page-navigation island with selectable items, pointer hover, search, and Escape-to-close behavior. Original navigation labels and design remain in `index.html` and `styles.css`.

## Files

- `index.html` — preview markup
- `styles.css` — component and responsive styles
- `script.js` — expand/collapse, selection, and search interactions
- `card.json` — Modern Navbar Collection metadata
- `NAVBAR_CODE.md` — copy-ready source guide
- `code.html` — generated implementation pages
