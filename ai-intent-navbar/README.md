# AI Adaptive Intent Navbar — Predictive Morphing Navigation

Navigasi prediktif generasi baru yang bertransformasi secara cerdas (*morphing navigation*) menyesuaikan persona dan minat pengunjung secara real-time berdasarkan section yang dibaca dan durasi dwell-time.

## ✨ Fitur Utama

| Fitur | Deskripsi |
|---|---|
| **Live Persona Detection** | Mendeteksi persona pengunjung secara otomatis (Explorer, Developer, Enterprise, Designer) saat membaca konten spesifik. |
| **Dynamic Morphing Menu** | Tautan menu, badge indikator kecerdasan (*confidence score*), dan tombol aksi (CTA) bertransformasi mulus tanpa reload halaman. |
| **Integrated Live Simulator** | Panel simulator di bagian atas layar untuk menguji morphing ke 4 persona pengunjung secara instan dengan satu klik. |
| **Dwell Time Tracking** | Menghitung durasi baca pengunjung di section tertentu menggunakan Intersection Observer untuk memprediksi ketertarikan. |
| **Interactive SDK Clipboard** | Tombol CTA Developer otomatis berubah menjadi perintah copy command package manager (`npm install @synapse/sdk`). |
