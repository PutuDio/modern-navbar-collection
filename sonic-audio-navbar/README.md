# Sonic Audio Navbar — Web Audio API Harmonic Navigation

Navigasi web futuristik berbasis pendengaran (*soundscape navigation*) yang ditenagai oleh Web Audio API sintetis native browser tanpa file MP3 eksternal. Setiap menu memiliki karakteristik frekuensi dan synthesizer instrumen yang khas.

## ✨ Fitur Utama

- **Native Audio Synthesis**: Menggunakan oscillator, gain nodes, filter biquad, dan reverb envelope murni dari browser.
- **Harmonic Chord Strumming**: Menyapu kursor dengan cepat melintasi item navbar memainkan harmoni progresi arpeggio yang merdu.
- **Live Oscilloscope Ribbon**: Visualizer kanvas gelombang audio real-time yang memantul dan bereaksi dinamis saat nada berbunyi.
- **Unique Timbre Per Section**:
  - `Home`: Ambient Deep Sub-Bass
  - `Studio`: Polyphonic Square/Saw Synth
  - `Tracks`: Arpeggiator Sine Chime
  - `Artists`: Warm Electric Piano Tone
  - `Book Session`: Crisp Percussion Click
- **Mute & Volume Control**: Dilengkapi tombol toggle audio on/off yang ramah pengguna.
