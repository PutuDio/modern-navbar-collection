# Gooey Liquid Dock

Interactive icon dock with an SVG-filtered liquid indicator following the active item. Original navigation labels and design remain unchanged.

## Files

- `index.html` — preview markup
- `styles.css` — component and responsive styles
- `script.js` — active item and liquid indicator interactions
- `card.json` — Modern Navbar Collection metadata
- `NAVBAR_CODE.md` — copy-ready source guide
- `code.html` — generated implementation page

Preview is embedded in the collection gallery. Open `code.html` for the generated, copy-ready implementation page.
